Keep Shiftwise on your home screen or desktop, with Restock built in. Install directly from your browser—no app-store download needed.

Open Shiftwise

Open this page in your device’s browser, outside the ChatGPT in-app browser.

Android

Open Shiftwise in Chrome. Tap the ⋮ menu, then Add to Home screen or Install app. Follow the installation prompt.

iPhone · iOS

Open Shiftwise in Safari. Tap Share, then Add to Home Screen. Turn on Open as Web App if shown, and tap Add.

iPad · iPadOS

Open Shiftwise in Safari. Tap Share (then View More if needed), choose Add to Home Screen, enable Open as Web App if shown, and tap Add.

Linux

Open Shiftwise in Chrome or Chromium. Use the install icon in the address bar, or the browser menu’s Cast, save and share → Install page as app. It opens in its own window.

Ready for offline days

First open and unlock the app while online on each device. Wait until its offline status says it is ready. Your saved records remain encrypted on that device. Changes sync when you reconnect with Shiftwise open and unlocked.

For the same records on another device, sign in to the same account and unlock the same vault. Keep your vault passphrase safe; it cannot be reset to recover encrypted records.

This is an installable web app, not an APK, IPA, or Linux package. Installation and offline storage depend on browser support. Clearing browser data can remove unsynced records.
